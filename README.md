# 🌤️ Previsão do Tempo

App de previsão do tempo construído com Angular e Tailwind CSS, consumindo a API da OpenWeatherMap.

## 🔗 Demo

[previsaotempo-seven.vercel.app](https://previsaotempo-seven.vercel.app)

## ✨ Funcionalidades

- Busca de clima por nome de cidade
- Temperatura atual, descrição e ícone do clima
- Detalhes: pressão, visibilidade, mín/máx, nascer do sol
- Pôr do sol, cobertura de nuvens, umidade e vento
- Previsão para os próximos 5 dias
- Modo claro e escuro
- Design responsivo estilo glassmorphism

## 🛠️ Tecnologias

- [Angular 17+](https://angular.io)
- [Tailwind CSS 3](https://tailwindcss.com)
- [OpenWeatherMap API](https://openweathermap.org/api)
- [Vercel](https://vercel.com) — deploy

## 🚀 Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/Tatianecostadacosta/previsaotempo.git

# Entre na pasta
cd previsaotempo

# Instale as dependências
npm install

# Rode o servidor de desenvolvimento
ng serve
```

Acesse http://localhost:4200
